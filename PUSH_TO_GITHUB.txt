📌 STEP 1: Create GitHub Repository
───────────────────────────────────────────────────────────────
1. Go to: https://github.com/new
2. Repository name: portfolio-react
3. Description: Modern portfolio with dynamic theming
4. Make it PUBLIC ✓
5. DO NOT check any boxes (no README, .gitignore, license)
6. Click "Create repository"

📌 STEP 2: Copy Your GitHub Username
───────────────────────────────────────────────────────────────
After creating the repo, you'll see something like:
https://github.com/YOUR_USERNAME/portfolio-react.git

Copy YOUR_USERNAME (example: if your profile is github.com/abhay3020, 
then YOUR_USERNAME is: abhay3020)

📌 STEP 3: Run These Commands (ONE BY ONE)
───────────────────────────────────────────────────────────────
Open Terminal and run:

cd /Users/abhayambekar/Documents/projects/cl/portfolio-react

git remote add origin https://github.com/YOUR_USERNAME/portfolio-react.git
(Replace YOUR_USERNAME with your actual GitHub username)

git push -u origin main

📌 STEP 4: Deploy to GitHub Pages
───────────────────────────────────────────────────────────────
npm run deploy

✅ Your portfolio will be live at:
https://YOUR_USERNAME.github.io/portfolio-react/

🎯 ALTERNATIVE: Super Easy Vercel Deployment
───────────────────────────────────────────────────────────────
1. After pushing to GitHub (Steps 1-3 above)
2. Go to: https://vercel.com/login
3. Sign in with GitHub
4. Click "Add New..." → "Project"
5. Select "portfolio-react"
6. Click "Deploy"
7. ✅ Done! Live at: https://your-project.vercel.app
